# pam grants

[INTENT: NAVIGATION]

`gcloud pam grants` — Manage Privileged Access Manager (PAM) grants: the time-bound elevation instances requested against an entitlement.

## Subcommands

- [approve](approve/overview.md) — Approve a PAM grant with a reason
- [create](create/overview.md) — Create a PAM grant (request temporary elevation)
- [describe](describe/overview.md) — Show details of a PAM grant
- [revoke](revoke/overview.md) — Revoke a PAM grant with a reason
