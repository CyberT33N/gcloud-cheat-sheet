# Privileged Access Manager

[INTENT: NAVIGATION]

`gcloud pam` — Manage Privileged Access Manager (PAM) entitlements and grants: just-in-time temporary privilege elevation for select principals, with approval workflows, platform-enforced grant durations, and audit logging.

## Subcommands

- [check-onboarding-status](check-onboarding-status/overview.md) — Check the PAM onboarding status of a resource
- [entitlements](entitlements/overview.md) — Manage PAM entitlements
- [grants](grants/overview.md) — Manage PAM grants
