# `roles/aiplatform.tensorboardWebAppUser`

Grants access to the Agent Platform Tensorboard web app. Using the web app will incur charges.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/aiplatform.tensorboardWebAppUser` |
| Title | Agent Platform Tensorboard Web App User |
| Type | Predefined role |
| Launch stage | `BETA` |
| Included permissions | 1 |
| Service | [aiplatform](../overview.md) |
