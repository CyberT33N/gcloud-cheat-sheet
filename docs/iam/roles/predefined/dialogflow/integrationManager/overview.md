# `roles/dialogflow.integrationManager`

Can add, remove, enable and disable Dialogflow integrations.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/dialogflow.integrationManager` |
| Title | Dialogflow Integration Manager |
| Type | Predefined role |
| Launch stage | `GA` |
| Included permissions | 5 |
| Service | [dialogflow](../overview.md) |

## Permissions

`roles/dialogflow.integrationManager` grants 5 permissions across 1 services. Each service page lists exactly the permissions this role grants on that service and links every permission to its canonical page in the [central permission catalog](../../../../permissions/overview.md).

| Service | Permissions |
