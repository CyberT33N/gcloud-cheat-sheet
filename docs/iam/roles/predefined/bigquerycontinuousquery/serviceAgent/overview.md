# `roles/bigquerycontinuousquery.serviceAgent`

Gives BigQuery Continuous Query access to the service accounts in the user project.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/bigquerycontinuousquery.serviceAgent` |
| Title | BigQuery Continuous Query Service Agent |
| Type | Predefined role |
| Launch stage | `GA` |
| Included permissions | 1 |
| Service | [bigquerycontinuousquery](../overview.md) |
