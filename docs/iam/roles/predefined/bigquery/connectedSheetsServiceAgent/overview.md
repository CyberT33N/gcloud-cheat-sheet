# `roles/bigquery.connectedSheetsServiceAgent`

Grants Connected Sheets Service Account access to create and manage BigQuery jobs on the customers resources.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/bigquery.connectedSheetsServiceAgent` |
| Title | Connected Sheets Service Agent |
| Type | Predefined role |
| Launch stage | `GA` |
| Included permissions | 5 |
| Service | [bigquery](../overview.md) |
