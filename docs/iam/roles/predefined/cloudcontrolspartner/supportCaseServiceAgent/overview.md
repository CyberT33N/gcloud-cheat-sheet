# `roles/cloudcontrolspartner.supportCaseServiceAgent`

Gives the Partner Console service account access to support cases for workloads associated with a partner.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/cloudcontrolspartner.supportCaseServiceAgent` |
| Title | Cloud Controls Partner Support Case Service Agent |
| Type | Predefined role |
| Launch stage | `GA` |
| Included permissions | 1 |
| Service | [cloudcontrolspartner](../overview.md) |
