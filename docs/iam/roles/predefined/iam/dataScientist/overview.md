# `roles/iam.dataScientist`

Designed for a data scientist power user to manage data platform services and associated Compute services for analyzing data and building data processing, transformation and analysis pipelines.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/iam.dataScientist` |
| Title | Data Scientist |
| Type | Predefined role |
| Launch stage | `GA` |
| Included permissions | 1097 |
| Service | [iam](../overview.md) |
