# `roles/iam.supportUser`

Provide a user the ability to create and manage support cases in their own enterprise by viewing their GCP resource configurations, monitoring and logging information that may be needed for providing required information to GCP support.

## Role details

| Property | Value |
| --- | --- |
| Role ID | `roles/iam.supportUser` |
| Title | Support User |
| Type | Predefined role |
| Launch stage | `GA` |
| Included permissions | 6613 |
| Service | [iam](../overview.md) |
