# `roles/iam.workforcePoolAdmin`

Full rights to create and manage all workforce pools in the org, along with the ability to delegate permissions to other admins.

## Role details

| Property | Value |

| Role ID | `roles/iam.workforcePoolAdmin` |
| Title | IAM Workforce Pool Admin |
| Type | Predefined role |

| Included permissions | 38 |
| Service | [iam](../overview.md) |
